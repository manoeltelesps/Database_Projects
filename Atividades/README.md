# 🏫 Atividades — Sistemas Escolares

Atividades avaliativas de modelagem e manipulação de bancos de dados escolares. Na raiz, um exercício de criação de um `SistemaEscolar` com alunos, cursos, turmas e empréstimos de livros. Na subpasta `AtividadeNov/`, uma atividade mais completa sobre o banco `SalaDeAula`, cobrindo índices, busca textual, views, controle de acesso (roles/usuários), triggers e stored functions/procedures.

## 📂 Arquivos
| Arquivo | Descrição |
|---|---|
| `Atividade-Criação_de_Bancos_de_Dados_e _Tabelas.sql` | Cria o banco `SistemaEscolar` (Pessoa, Aluno, Curso, Turma, Autor, Livro e tabelas de relacionamento), com dados de exemplo e consultas de conferência |
| `Exercício1_20250814223003048.png` | Print do enunciado do exercício |
| `AtividadeNov/SalaDeAulaDDL.sql` | DDL do banco `SalaDeAula`: `Pessoa`, `Aluno`, `Professor`, `Curso`, `Turma`, `Aluno_Curso`, `Aluno_Turma`, `Materia` e `Avaliacao` |
| `AtividadeNov/sala-dml.sql` | Massa de dados gerada para popular o `SalaDeAula` (milhares de `INSERT`s em `Pessoa`, `Aluno`, `Aluno_Turma`, `Avaliacao` etc.) |
| `AtividadeNov/Questoes.sql` | Respostas às questões da atividade: índice, busca full-text, views, roles/usuários, triggers e functions/procedures para cálculo de nota final e medidas disciplinares |
