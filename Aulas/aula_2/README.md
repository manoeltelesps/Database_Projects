# 📖 Aula 2 — Modelagem de Livraria

Modelagem do banco `Livraria`, separando o script de criação (DDL) do script de manipulação de dados (DML). Estrutura autores, livros e pessoas, com uma tabela de relacionamento `Emprestimo` para registrar empréstimos de livros. O modelo entidade-relacionamento está ilustrado em `modelo.jpeg`.

## 📂 Arquivos
| Arquivo | Descrição |
|---|---|
| `Livraria.sql` | DDL: cria o banco e as tabelas `Autor`, `Livro`, `Pessoa` e `Emprestimo`, com inserções e consulta iniciais |
| `manipulacaoLivraria.sql` | DML: inserções adicionais de autores, livros e pessoas, um empréstimo e uma exclusão de livro |
| `modelo.jpeg` | Diagrama do modelo entidade-relacionamento da Livraria |
